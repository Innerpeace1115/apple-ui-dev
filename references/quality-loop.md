# 质量闭环 · quality-loop.md

> **风格保证不能靠自觉。** 每次生成 APP 后必须完整跑完本章闭环；
> 闭环没跑完 = 没做完。任何一步失败 → 修复 → **从第 1 步重跑整个闭环**
> （修复本身经常引入新问题，只重跑失败步是不够的）。

## 1. 七步闭环

| # | 步骤 | 命令 / 动作 | 通过标准 |
|---|---|---|---|
| 1 | 静态校验 | `node check.mjs` | 退出码 0，0 处错误 |
| 2 | 起服务 | `npx serve .` / `python -m http.server` | 页面可访问 |
| 3 | 逐页功能验证 | 浏览器真实操作（可用 browseruse 自动化） | 见第 2 节验证矩阵，全部 ✓ |
| 4 | 视觉验证 | 截图 light + dark 各一张 | 无布局破碎、无对比度事故、毛玻璃四态可见差异 |
| 5 | 交付报告 | 输出验证矩阵 + 截图路径 | 用户可见的完成证据 |

## 2. 验证矩阵（第 3 步的最小集合）

| 检查项 | 操作 | 预期 |
|---|---|---|
| 页面切换 | 逐个点侧栏入口 | 目标页显示、其余隐藏、高亮跟随 |
| 明暗切换 | 设置页月亮图标 | 全站令牌切换，无遗漏的浅色块 |
| 强调色 | 标题栏色点 | 按钮/选中态/焦点环同步变色 |
| 毛玻璃 关 | 设置页开关 | 全站恢复实底，无模糊残留 |
| 毛玻璃 三档 | 轻盈→标准→浓郁 | 相邻档位肉眼可辨（透明度轴），浓郁档壁纸色透入卡片 |
| 关键交互 | 每个按钮/开关/弹窗真实点击一次 | 功能正常，无控制台报错 |
| 毛玻璃预览 | 设置页预览台 | 与全站材质同步变化 |

有浏览器自动化时用脚本断言（computed style / class / hidden 状态），
没有时逐项人工核对——**不许跳项**。

## 3. 截图规范

- light + dark 各一张全窗截图；改动集中在某面板时补 `?only=<面板id>` 特写。
- 文件名带主题与页名：`shot-light-home.png`。
- 截图即交付物：用户不看代码，先看图。

## 5. 失败模式库（全部真实踩过）

### 5.1 `[hidden]` 隐藏失败
**症状**：切页面后旧内容还在。
**根因**：`.grid-3`、`.btn` 等 author `display` 规则优先级高于 UA 的
`[hidden]{display:none}`。
**修复**：引用层补 `[data-page][hidden] { display: none !important; }`。

### 5.2 自定义属性循环引用 → 全站变透明
**症状**：开毛玻璃后所有面板 `rgba(0,0,0,0)`。
**根因**：`--bg-raised: color-mix(… var(--bg-raised) …)` 引用自身，浏览器整组判无效。
**修复**：tokens.css 拆两层 `--bg-raised-solid`（真值）+ `--bg-raised`（指向它）；
JS 的 color-mix 只引用 `-solid`。

### 5.3 毛玻璃"开了但看不见"
**根因 A**：标题栏/侧栏背后是实底窗口，blur 无物可糊。
**修复**：毛玻璃开启时窗口底换半透明（color-mix 派生），壁纸透进来。
**根因 B**：壁纸彩色光斑全在四角，内容区背后是深色底。
**修复**：桌面渐变加一块正对窗口中心的色斑。
**根因 C**：多层半透明白叠加（卡片×内容×窗口）复合后仍近不透明。
**修复**：三层的 alpha 是乘法关系，逐层调低（见 GLASS_PRESETS 数值）。

### 5.4 check.mjs 报 color
引用层写了字面色值 → 移入 tokens.css 定义为令牌，业务里改 `var()`。
图标 sprite 的 `id` 与注释里的示例色会被自动豁免，不用担心。

### 5.5 侧栏高亮与视图不同步
nav 点击与 `showPage()` 必须在同一个监听器里；URL 参数恢复页面时
也要同时恢复 `is-active`（漏掉就出现"内容对了、高亮没动"）。

### 5.6 只调 blur 半径没效果
壁纸是平滑渐变，14px 与 44px 模糊肉眼无差。材质强度必须**双轴**：
模糊半径 + 表面透明度（后者才是可感知轴）。

### 5.7 深色下出现浅色残块
新增令牌只给了浅色值。**每个新令牌必须同时补 `data-theme='dark'` 值**。

### 5.8 设计模式拦截了业务点击
这是特性：设计模式开启时 capture 阶段拦截全部 click。验证业务交互前
先退出设计模式；验证设计模式时预期业务点击无效。

## 6. 与 CI / 习惯的接法

- `check.mjs` 退出码非 0 即失败，可挂 pre-commit 或 CI。
- 截图脚本可固化（参考 apple-ui-kit/shot.mjs：playwright + URL 参数出图）。
- 会话级修改在 sessionStorage（设计模式），演示前记得「重置」。
